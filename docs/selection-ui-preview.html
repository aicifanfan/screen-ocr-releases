  • 触摸目标 40px：工具栏按钮在 pointer: coarse 下加高，拇指可点。
  • 不新增纵向 margin：行距用 line-height 调整，跨行选区才不会出现白色断带。
  • 图区限高：堆叠后若图占满屏，文字被挤出首屏，联动就失去意义。
  • 不自绘手柄：触屏 Windows 由 Chromium 绘制原生手柄，自绘会丢系统复制与输入法。
